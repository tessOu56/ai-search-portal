# Spec Reviews（開發前審查報告）

feature / ticket 開工前的 spec review 報告存放處。規範見 [docs/spec-review.md](../../docs/spec-review.md)；模板見 [develop-md/ai-skills/spec-review/templates/spec-review-report.md](https://github.com/tessOu56/develop-md/blob/main/ai-skills/spec-review/templates/spec-review-report.md)。

- 檔名：`YYYY-MM-DD-<slug>.md`
- 裁決欄必填：`ready` / `ready-with-notes` / `blocked`
- 審查發現的既存問題 → 登錄 [../issues.md](../issues.md)（CR-xxx），不在報告內順手修
